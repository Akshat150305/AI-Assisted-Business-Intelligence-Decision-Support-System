> **All data is synthetic.**

## How to use this file

1. In Power BI Desktop choose **Home > Enter data**, create an empty table named `_Measures`, load it.
2. For each measure below: select `_Measures`, **New measure**, paste the DAX, set the format.
3. Check each measure against the answer key (build_guide.md section 8).

**Measure vs calculated column vs Power Query.** A *measure* is calculated at query time for the current filter context (use it for every KPI and ratio). A *calculated column* is stored per row when the model loads (use rarely, for row-level labels). A *Power Query step* reshapes data before it is loaded (already done by the Python pipeline). Ratios must be measures: an average of row-level ratios is not the ratio of totals.

### Profit Margin %

```dax
Profit Margin % =
DIVIDE ( [Profit], [Revenue] )
```

- **Format:** `0.00%`
- **Why:** Profit per unit of revenue. A RATIO MEASURE: it must divide the two totals, never average line margins. DIVIDE returns blank instead of an error when revenue is 0. Formatted as % in Power BI (0.3668 shows as 36.68%).

### Repeat Customers

```dax
Repeat Customers =
COUNTROWS ( FILTER ( VALUES ( fact_sales[customer_id] ), CALCULATE ( DISTINCTCOUNT ( fact_sales[order_id] ) ) >= 2 ) )
```

- **Format:** `#,##0`
- **Why:** VALUES gives the customers in the current filter. For each one, CALCULATE counts that customer's distinct orders (context transition); FILTER keeps those with 2 or more.

### Repeat Customer Rate

```

- **Format:** `0.0%`
- **Why:** Share of active customers who ordered 2+ times in the selected period. NOT a churn measure. About 97% in this synthetic data, so it does not discriminate.

### Top 10 Customer Revenue

### Revenue PM

```

- **Format:** `#,##0`
- **Why:** Revenue of the previous month. Needs dim_date to be a marked, gap-free date table.
- **Answer key:** no direct column; verified through its parts and the filtered checks in build_guide.md

### Revenue MoM %

```dax
Revenue MoM % =
DIVIDE ( [Revenue] - [Revenue PM], ABS ( [Revenue PM] ) )
```

- **Format:** `0.0%`
- **Why:** (current - previous) / ABS(previous), the same rule as SQL and Python. Blank for the first month. Meaningful on a MONTH axis; do not put it on a card with a multi-month slicer.
- **Answer key:** `kpi_monthly[revenue_change_pct]` (month by month)
